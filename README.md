# mlcode notebooks

Colab notebooks for the PyTorch problems on [mlcode](https://mlcode-io.vercel.app).

PyTorch has no WebAssembly build, so these three problems cannot run in the
browser the way the other sixty-five can. Colab already has torch installed and
a GPU attached, so they run there instead.

Each notebook asks for a code from the problem page. That code is what fetches
the hidden tests at grade time and records the attempt against your account, so
the tests and the reference solutions never live in this repository.

Generated by `scripts/generate_notebooks.py` in the main repository. Edits here
are overwritten.
